# 3D Profile Visualization

A simple, clean 3D profile visualization using Three.js CSS3D renderer.

## Features

- **3D Visualization**: Interactive 3D profile cards
- **Multiple Layouts**: Table, Sphere, Helix, and Grid arrangements
- **Smooth Animations**: TWEEN.js powered transitions
- **Mouse Controls**: 3D navigation with TrackballControls
- **Responsive Design**: Works on all devices

## How to Use

1. Open `index.html` in a web browser
2. Wait for the visualization to load
3. Use the buttons at the bottom to switch between layouts:
   - **TABLE**: Grid arrangement
   - **SPHERE**: Spherical distribution
   - **HELIX**: Spiral arrangement
   - **GRID**: 3D cube layout
4. Use mouse to rotate, zoom, and pan the 3D view

## Files

- `index.html` - Main HTML file with embedded CSS
- `app.js` - JavaScript application logic
- `README.md` - This documentation

## Technologies Used

- Three.js r110 - 3D graphics library
- TWEEN.js - Animation library
- CSS3D Renderer - HTML element 3D rendering
- TrackballControls - 3D navigation

## Live Demo

Open `index.html` in any modern web browser to see the visualization in action.

The system includes 20 sample profiles with names, ages, countries, interests, and net worth data displayed as interactive 3D cards.
